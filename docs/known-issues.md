# 已知问题与边界 · 0.1.3

0.1.3 增加紧凑任务卡片和八方向缩放。长标题默认单行省略，悬停或编辑查看全文。真实鼠标已验证八个缩小方向；桌面 / 悬浮的放大、缩小和边界限制通过程序内 HWND 测试，多屏与不同 DPI 的真实设备验收仍待补充。

0.1.2 修复模式按钮连续点击后窗口消失：旧逻辑切回桌面时会立即把窗口嵌入壁纸层，进程仍在但窗口可能被遮挡。现在按钮和托盘切换都会保持窗口可见，桌面模式用“放回桌面”明确执行嵌入；悬浮与已唤出的桌面模式之间复用同一个窗口和 HWND，避免在 Click 处理中关闭窗口。连续 30 次真实 WPF 按钮事件及随后的健康检查定时器回归通过；此项不等同于物理鼠标连续点击验收。

0.1.1 已修复“双击 EXE 没有可见窗口”：手动打开与托盘唤出会重建为临时前台窗口，提供任务栏入口和“放回桌面”按钮；保存的桌面模式偏好不变。再次启动通过单实例事件唤出原窗口，且向原进程授予本次用户打开操作的前台激活许可。

1. **桌面宿主兼容性**：本机 Windows 11 build 26200 已验证实际 `WorkerW` 父窗口挂接。不同 Windows 10/11 更新、动态壁纸软件、远程会话或 Explorer 改动可能影响布局和输入。失败时回退到普通非置顶窗口，保留数据和托盘。`Win+D` 的真实可见性、其他应用遮挡和中文输入法仍需人工验收。
2. **Explorer / DPI / 多屏**：已实现宿主健康检查、最多三次恢复、屏幕变化消息处理和屏幕内约束；尚未通过真实重启 Explorer、拔插显示器和跨 DPI 操作来证明全部行为。
3. **提醒形式**：使用 Windows Shell 原生托盘通知，没有后台 Windows 服务。通知点击返回最近一次提醒，托盘和编辑器支持稍后 10 分钟。未实现进程退出后由通知中心的任意旧通知精确激活；通知是否显示受系统设置、勿扰模式、锁屏和系统策略控制。已完成任务不再派发普通提醒，但已经送达系统的通知不能自动撤回。
4. **半透明主题**：本版提供半透明玻璃配色，不保证系统级 Acrylic / Mica 或壁纸模糊。
5. **键盘与触控**：使用原生 WPF Slider 的键盘、触控和轨道行为。绑定、整数保存、完成样式已自动验证；真实鼠标、键盘、触屏、输入法仍需人工测试。
6. **备份规模**：JSON 恢复限制为 100 MB，避免意外载入巨型文件。较大长期数据集尚未进行性能基准；可保留完整 SQLite 数据库迁移。
7. **发布**：本版为 Windows x64 绿色程序，未制作安装器、自动更新器或代码签名。更新需退出旧程序再替换文件。不要同时对同一数据目录运行外部数据库编辑器。

这些边界不改变进度、历史记录、重复实例和备份的业务规则。未测试项目没有标记为通过。
