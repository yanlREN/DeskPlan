### 提醒与恢复

- [ ] 建立未来 1 分钟提醒，确保 Windows 允许通知且勿扰关闭，实际收到系统通知。
- [ ] 点击最新通知回到对应任务；通过托盘或编辑器延后 10 分钟，等待后仅提醒一次。
- [ ] 提醒前把任务完成，不派发普通提醒；重启不会重复提醒已发送的计划。
- [ ] 休眠后恢复、系统时间前后调整时，没有旧提醒风暴；两小时内仍有效提醒适当补发。
- [ ] 无效 JSON 不影响已有数据；有效恢复前显示确认，并在 `backups/` 留下原数据库副本。
