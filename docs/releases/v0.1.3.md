# DeskPlan v0.1.3 · 紧凑任务卡片与八方向缩放

本次更新让任务列表更紧凑，并让窗口的四条边、四个角都能拖动缩放。

## 更新内容

- **更紧凑的任务卡片**：默认字号下高度由约 93 降至约 63 DIP，缩小约三分之一；默认窗口可完整显示三条计划。
- **更清晰的层次**：标题与进度、时间与状态、滑块组成三行，缩小圆角和留白，加入轻微悬停描边。
- **长标题提示**：卡片内单行省略，悬停可查看完整标题和备注，也可通过“编辑”查看。
- **八方向缩放**：四条边、四个角均可拖动，鼠标显示相应方向；拖动左边或上边时，对边保持固定。
- **保存窗口尺寸**：松手后保存位置与尺寸，保留最小尺寸和屏幕工作区约束。
- **快速拖动修复**：补齐松手时的最终位移，避免快速拖动没有生效或左上方向出现累计偏移。
- 更新图文手册、快速入门、离线 HTML 说明书和界面截图。

## 下载和升级

1. 下载下方 Assets 中的 **DeskPlan-0.1.3-win-x64.zip**。
2. 旧版用户先在设置中导出 JSON 备份，再右键托盘图标 → **退出 DeskPlan**。
3. 完整解压新版，双击 **DeskPlan.exe**；原有计划、进度和设置继续保存在 `%LOCALAPPDATA%\DeskPlan`。
4. 双击包内 **使用说明.html**，可离线阅读图文手册。

支持 Windows 10 / 11 x64，自带 .NET 运行时，无需管理员权限。`Source code` 为开发源码。程序为绿色包，没有安装器、自动更新或代码签名。

## 验证情况

- 54 项单元测试通过，涵盖业务规则和八方向缩放计算，包含不同缩放比例、负坐标显示器、最小尺寸与工作区限制。
- 42 项本机窗口检查通过，包含桌面 / 悬浮宿主的缩放命中区、实际 HWND 矩形变化、尺寸保存、快速松手和模式切换回归。
- 在已唤出的桌面模式下，实际鼠标拖动四边四角均验证了缩小与对边固定。

实际验证环境为 Windows 11 x64 build 26200。不同 DPI 的计算测试不等同于多屏硬件验收；真实重启 Explorer、Windows 10、触控和通知展示等仍有人工验收项目。完整边界见 [已知问题](https://github.com/yanlREN/DeskPlan/blob/v0.1.3/docs/known-issues.md)。
