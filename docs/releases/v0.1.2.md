# DeskPlan v0.1.2 · 首个正式发布版本

DeskPlan 是一个面向 Windows 的离线桌面每日计划工具：安排计划，拖动进度，按日、周、月回顾执行情况。无需登录，数据保存在本机。

## 下载和使用

1. 下载下方 Assets 中的 **DeskPlan-0.1.2-win-x64.zip**。
2. **完整解压**后双击 **DeskPlan.exe**。Windows 10 / 11 x64，无需另装 .NET，无需管理员权限。
3. 双击解压目录内 **使用说明.html**，离线阅读图文操作手册。

`Source code` 是开发源码，不是可运行安装包。首次打开可能稍慢。本版没有安装器、自动更新或代码签名。

## 本版功能

- 计划标题、日期、时间、备注，每天 / 工作日 / 每周重复。
- 0–100% 进度滑块；完成自动变灰划线，保留完成与修改记录。
- 悬浮置顶、桌面壁纸层、系统托盘与登录后自动启动。
- 日 / 周 / 月回顾、趋势图、月历、复盘总结及历史未完成清单。
- 本地到点 / 提前提醒、稍后 10 分钟。
- SQLite 保存、JSON 全量备份恢复、CSV 导出。
- 浅色、深色、半透明主题，透明度与字号设置。

## 已修复

- 手动打开 EXE 时，已在运行的桌面组件会唤到前台。
- 连续切换显示模式保持窗口可见，悬浮与已唤出的桌面模式复用窗口；需要贴回壁纸层时点击 **放回桌面**。
- 设置页版本号从程序读取，避免显示旧版本。

## 更新与兼容性

旧版用户请先导出 JSON 备份，从托盘 **退出 DeskPlan** 后替换程序。数据保存在 `%LOCALAPPDATA%\DeskPlan`，升级不会自动清空历史。

本机 Windows 11 build 26200 已通过 33 项业务测试和 30 项窗口集成检查，包含连续触发 30 次按钮事件。该检查不等同于物理鼠标连续点击；Windows 10、多屏跨 DPI、Explorer 重启、触控和真实通知展示仍有人工验收项目。

桌面嵌入受 Explorer 环境影响，不兼容时使用普通窗口回退或悬浮模式。提醒依赖程序运行与 Windows 通知设置；完全退出后不会继续提醒。详见 [已知问题](https://github.com/yanlREN/DeskPlan/blob/v0.1.2/docs/known-issues.md)。
